# Requisitos do Aplicativo do Congresso (Congress App)
# Note: Este projeto utiliza Node.js, portanto os "requirements" são gerenciados via package.json.

## Dependências de Sistema
- Node.js >= 18.0.0
- npm >= 9.0.0 (Gerenciador de Pacotes)

## Dependências Principais (npm)
- react: ^19.2.4
- vite: ^8.0.0
- @supabase/supabase-js: ^2.100.1 (Banco de dados)
- @capacitor/core: ^8.3.0 (Versão Mobile)
- luxide-react: ^0.577.0 (Ícones)
- xlsx: ^0.18.5 (Exportação de dados)

## Como Instalar no Novo PC
1. Instale o Node.js.
2. Abra o diretório do projeto.
3. Execute: npm install
4. Crie o arquivo .env (veja CONFIGURACAO_LOCAL.md)
